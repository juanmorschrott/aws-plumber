# UC-003 CLI Appearance and Aesthetic

## Goal
Define the visual style and interaction aesthetic for the AWS Plumber CLI.

## Description
The CLI should feel like a modern, professional 8-bit terminal interface.
It should use a dark theme with AWS-inspired yellow accents, while staying clean and readable.

## Requirements
- Interactive CLI experience with keyboard navigation and clear screen states.
- Modern 8-bit-inspired style, including pixel-inspired borders, headings, and separators.
- Predominantly dark color palette.
- AWS yellow accent for highlights, actionable elements, and important status text.
- Consistent spacing and typography-like layout for readability.
- Minimal visual clutter, with a polished appearance suitable for outage operations.

## Visual Elements
- Dark background or terminal base with subtle contrast zones.
- Yellow accents for selected menu items, prompts, and success/highlight states.
- Neutral grayscale text for primary content and labels.
- Distinct visual separation between sections and tool screens.

## UX Expectations
- Main menu clearly lists available tools with a highlighted selection bar.
- Instance selection list shows up to 10 items at once and highlights the current cursor position.
- Input prompts use a clean label/value layout.
- Success and error results are displayed with clear status blocks and color-coded messages.

## Notes
- The aesthetic should evoke a fast, operational toolbox rather than a gimmicky game.
- The AWS yellow accent should be used sparingly to support readability and focus.
- This skill is a design guidance document for the CLI appearance and interaction style.
